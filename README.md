# StudyFlow 📚

StudyFlow is a student productivity web application designed to help students organize their studies, manage tasks, and stay productive.

## Features
- Clean and user-friendly dashboard
- Study task management
- Student profile interface
- Organized navigation

## Tech Stack
- HTML
- CSS
- JavaScript

## Getting Started
Clone the repository and open `index.html` in your browser.
